BookStoreCRUD

A Java standalone application using MySQL and JDBC.

Technologies Used

- Java
- Eclipse IDE
- MySQL Server
- MySQL Connector/J
- JDBC

Features

- Create: Insert book records
- Read: Display all books
- Update: Update book prices
- Delete: Delete book records

Database

Database name: "bookstore_db"

Table name: "book"

How to Run

1. Create the "bookstore_db" database in MySQL.
2. Create the "book" table and insert sample records.
3. Add MySQL Connector/J to the Eclipse project build path.
4. Update the database connection settings in "DBConnection.java".
5. Run "Main.java" as a Java Application.
